# ☁️ WordCloud Generator App

A Streamlit web app that generates beautiful WordClouds from PDF, DOCX, and TXT files.

**Live Demo:** Coming soon on Streamlit Cloud
**GitHub:** amrit-09-code/wordcloud-app

### Features
- 📄 Upload PDF / DOCX / TXT files
- ☁️ Generates custom WordCloud
- 📊 Word Count Table (Top 50 words)
- 📈 Top 20 Words Bar Chart
- 💾 Download WordCloud as PNG / JPEG / PDF

### Tech Stack
Python, Streamlit, WordCloud, Matplotlib, Plotly, PyPDF2

### How to Run Locally
```bash
pip install -r requirements.txt
streamlit run cloud.py
